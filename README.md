# 颂读 · 禅宗四经 文白对照

研读型佛学读经网站。收录禅宗四部经典——**心经、金刚经、坛经、楞伽经**，原文与白话逐段对照，
界面骨架参考 [读通鉴](https://www.dutongjian.com/)：左侧经目树、中间正文、右畔诵读助手。

## 功能

- **逐段文白对照**：左右 / 上下 / 仅原文 / 仅白话 四种显示模式
- **竖排古籍**：一键竖排（writing-mode），如对古本
- **术语点线注解**：原文术语带点线下划线，点击弹释义卡（术语 / 人物 / 地名三类，101 条）
- **段级工具栏**：收藏段落、标签、术语解、复制本段链接
- **研读便利**：章节目录树、字号 / 字体（宋体 / 文楷）调节、纸色 / 夜读主题、阅读进度记忆
- **全文检索**：四经原文 + 白话客户端检索，命中高亮、直达段落
- **书签页**：收藏按经章分组，标签筛选

## 内容版权

- 原文底本：《大正新修大藏经》公版经文（心经 T251 玄奘译 / 金刚经 T235 鸠摩罗什译 /
  坛经 T2008 宗宝本 / 楞伽经 T670 求那跋陀罗译）。
- 白话译文：AI 生成，原创表述，仅供参考。
- 术语释义：原创编写。

## 数据管线

```
data/raw/sutras.json        原文（经 → 章 → 段）
translations/<经>/chNN.json 白话译稿分片 {sutra, chapter, start, paras}
glossary.json               术语表
        │  npm run build:data
        ▼
public/data/{index,<经>,search,glossary}.json
```

构建脚本 `scripts/build-data.mjs` 校验白话分片与原文逐段对齐（断点 / 越界 / 缺口即报错），
未译段落以「白话整理中」占位、原文照常可读。

## 开发

```bash
npm install
npm run build:data   # 生成站点数据
npm run dev          # http://localhost:5199
npm run build        # 类型检查 + 产出 dist/（纯静态，可部署任意静态托管）
```

技术栈：Vite + Vue 3 + TypeScript，无后端；书签 / 进度 / 设置存 localStorage。
字体：Noto Serif SC / 霞鹜文楷 / 马善政楷书（@fontsource）。
